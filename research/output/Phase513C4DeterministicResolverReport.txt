--------------------------------------

escrito Target Layer ID (-0009). El path se marcó invalid_request antes de
adquirir streams. El provider fue corregido para escribir el layer.id ya
capturado, sin crear parámetros ni habilitar Target Identity Valid.

3. Harness determinista
-----------------------

Se añadió ValidateGeometryTargetResolverDeterministic.jsx. El harness crea
composiciones nuevas, activa cada comp, crea Shape Layer → Group → Contents →
Rectangle Path, captura con el provider productivo, relee los parámetros de
identidad y sólo después intenta renderizar.

El harness registra Target State Version, Target Identity Valid, Target Layer
ID, Target Unique Stream ID, Path Version, Path Valid, Path Count e índices y
tokens por segmento. Cada ejecución escribe un RUN_ID antes del render.
