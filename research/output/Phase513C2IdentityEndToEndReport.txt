4. Resolución AEX
-----------------

ResolveGeometryTargetPathFromAfterEffects() consume únicamente el payload
serializado, obtiene la capa por layerId, resuelve el Root Vectors Group por
Match Name, recorre los índices propertyIndex-1 y valida el Match Name contra
el token en cada segmento. Obtiene Unique Stream ID sólo después de alcanzar
el Rectangle Path y libera cada StreamRef en el mismo ámbito.

La función no busca alternativas y Render ignora el resultado durante esta
fase; Group Transform permanece desactivado.

La comparación CEP == stored params está confirmada para el caso simple. La
comparación stored params == resolución AEX no pudo observarse en runtime sin
introducir logging o una interfaz diagnóstica en el render; no se añadió tal
instrumentación.
